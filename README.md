# HTML & CSS CV / Personal Resume Project 📄

A clean, semantic, and modern personal resume webpage built using **HTML5** and **CSS3**. Designed with maintenance best practices like CSS `:root` variables, responsive layout structures, and professional project showcases.

## 📌 Key Features

- **Semantic HTML5 Architecture:** Built using clean structural tags (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`) for enhanced SEO and web accessibility (a11y).
- **CSS3 Custom Properties (`:root` Variables):** Centralized color palette management making theme adjustments and future styling scalability effortless.
- **Modern Responsive Card UI:** Box-shadow depth, custom typography, clean dividers, and clean link hover transitions for a polished visual aesthetic.
- **Featured Projects Section:** Showcases key active applications including **CalcHub (Multi-Calculator Web App)** with live repository links.
- **Secure & Direct Links:** Integrated `mailto:` protocol and external links (`LinkedIn`, `GitHub`) utilizing `rel="noopener"` security protocols.
